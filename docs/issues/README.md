# Issues de evolução

Este diretório registra propostas de mudança antes da implementação. Uma issue
com estado **Aguardando validação** descreve uma intenção de produto, mas ainda
não autoriza alterações no código nem nos documentos que são fonte de verdade
do site.

## Fluxo

1. Elaborar a issue com escopo, regras, critérios de aceite e impactos.
2. Validar a issue e registrar nela eventuais decisões.
3. Alterar o estado para **Aprovada para implementação**.
4. Antes ou junto da implementação, atualizar os documentos indicados pela
   issue.
5. Implementar e validar o código.
6. Registrar o resultado e alterar o estado para **Concluída**.
